# Runnable prototype

Nuxt 3 / Vue prototype implementing Statement Drop, Unhedged Risk Report, Zero-Risk Activation Switch, Sovereign Pulse, Dispatch, and P1 → PCO Spawner.

```bash
cd app
npm install
npm run dev
npm run build && npm run start
```

The data is local reactive state, ready to replace with authenticated telemetry, dispatch, and settlement APIs.
