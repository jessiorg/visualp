# Two-surface sovereign operating model

## Sovereign Pulse
Pulse is the state surface: live balance sheet, survival/continuity floor, inflows, outflows, savings, commitments, free-cash-flow ticker, telemetry and leading indicators. It answers: what is true now and which constraint matters next?

## Dispatch
Dispatch is the action surface: agents, missions, blockers, expected value, approvals, wholesale block aggregation, supplier/customer coordination and settlement evidence. It answers: what changes next, who is authorised, and how does value settle?

## Operating loop
Pulse detects a gap. Dispatch creates a mission. Compatible P1/PCO demand is aggregated into a wholesale block. An agent proposes execution; an approval queue holds actions requiring human authority. Settlement records counterparty, amount, currency, timestamp, evidence and realised outcome. Only then is the result written back to Pulse.

Autonomy is bounded by permissions, spending limits, escalation rules, audit logs and rollback/hold states. The architecture must never imply that an agent has authority merely because it can produce a recommendation.
