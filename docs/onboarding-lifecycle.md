# Onboarding lifecycle and screen progression

The Occam pipeline minimises time-to-first-value:

1. Statement Drop: the user submits a plain-language constraint, bill, goal or operational pain.
2. Unhedged Risk Report: the system identifies exposure, cost of inaction, unknowns and a possible hedge.
3. Zero-Risk Activation Switch: the user authorises a bounded intervention with measurable downside and success criteria.

After evidence, the system earns permission for richer telemetry and larger missions. The screen sequence is Statement → Risk → Activation → Sovereign Pulse → Dispatch → controls/risk → P1→PCO Spawner. State and action remain separate: Pulse observes; Dispatch executes.

Rejected alternative: demanding bank, health, accounting and procurement integrations before demonstrating value. The design instead starts with a statement and progressively earns trust.
