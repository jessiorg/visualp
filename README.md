# visualp

Private source and documentation archive for the P1 / PCO lifecycle prototype: visual people, visual companies, sovereign pulse, dispatch, economics, and reinvestment architecture.

## Contents
- `docs/` — concepts, operating model, economics, tax notes, and diagrams.
- `media/README.md` — generated visualization catalog and media IDs.
- `prototype/README.md` — local reconstruction and source inventory.

The generated visualization assets remain available in the Poke media library by the IDs catalogued in `media/README.md`.
